Terraform module to deploy a basic Azure Monitor baseline for a Log Analytics Workspace, including Action Group, Scheduled Query Alerts, and built-in Data Collection Rules.

## Overview

This module provides a lightweight Azure Monitor baseline for managed workloads.

It focuses on:
- Scheduled Query Alerts v2
- Action Group email notifications
- Built-in Data Collection Rules for VM Insights, Windows Event Logs, and Linux Syslog
- Optional managed identities for alert rules
